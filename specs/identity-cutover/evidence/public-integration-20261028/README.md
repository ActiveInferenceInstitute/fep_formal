# Public identity integration record

This portable projection records the namespace migration's local validation.
`summary.json` states its source identity, measured results and limits.
`local-artifact-hashes.json` identifies the original local artifacts by their
unchanged byte hashes. The complete original packet remains preserved locally;
this public projection contains no workstation paths or private execution logs.
The projection is not the original native receipt or a signed attestation.

Initial failed and interrupted runs remain identified beside later results.
Local test coverage, native compilation, rendering, downstream checks and
historical custody each retain their own boundaries. None supplies hosted,
release, scientific or general semantic acceptance.

The maintained [migration status](../../../../docs/identity-migration-status.md)
records subsequent source-pair and main-branch integration results.
