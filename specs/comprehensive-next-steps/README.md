  demonstrate a residual query need instead of building a competing registry.
- Existing scalar and generic Gaussian semigroups have different parameter
  assumptions. L02 extracts genuinely shared transport, preserving both.
- Released Lean names and types remain stable by default. The new Landauer
  support bridge does not itself satisfy a request to replace an old primary
  type; that change requires explicit reviewed migration.
- The existing H3 preflight rejects three carrier byte changes from the Lean
  migration. Header similarity does not waive the immutable source checks.
- Continuous-path construction has a separate pinned-library gate. A generator,
  projective family or countable trajectory is not a continuous-path measure.
