# Choices ledger

## Portable queries reuse the delivered join

**When:** G01 planning reconciliation.

**Choice:** A library caller asking for assumptions or proof relations should
query the existing portable methods model. Adding a second generated semantic
snapshot would create two documents that must stay identical.

**Gap:** The older query Issue describes a missing portable join, while the
current methods API already supplies it.

**Reach:** A02 must demonstrate a remaining typed-query operation and reuse the
current metadata, maturity and graph owners.

**Verdict:** sound; this avoids a second semantic source and duplicate artifacts.
**Confidence:** high.

## Gaussian transport preserves distinct models

**When:** G01 planning reconciliation.

**Choice:** Shared semigroup transport can have one proof owner, while the
scalar model keeps its arbitrary positive diffusion rate and the generic model
keeps its precision-derived covariance. Similar theorem names alone do not
justify replacing one model with the other.

**Gap:** The deduplication Issue's name-count criterion does not express these
different assumptions.

**Reach:** L02 needs a real common transport theorem and exact public consumers;
it cannot specialize the scalar model merely to reduce names.

**Verdict:** sound; preserves the actual carriers and released semantics.
**Confidence:** high.

## Landauer strengthening starts with a compatible support theorem

**When:** G01 planning reconciliation.

**Choice:** A new caller can consume the derived path-model bound, while old
callers retain their released theorem types. Removing an old hypothesis changes
that public type and needs its own reviewed migration.

**Gap:** Issue88 asks to remove a premise, while the compatibility contract
preserves released statements by default.

**Reach:** F02's bridge and any subsequent primary replacement have separate
acceptance. A bridge alone cannot close the broader Issue.

**Verdict:** sound; exposes the stronger derivation without claiming an
unreviewed breaking replacement.
**Confidence:** high.

## H3 migration is explicit and prospective

**When:** G01 planning reconciliation.

**Choice:** Current carrier wrappers changed during the Lean upgrade, so the
existing frozen preflight rejects them. A reviewed execution contract must say
which epoch is being run; changing the old recorded hashes would erase that
distinction.

**Gap:** The roadmap requests fresh H3 execution after a toolchain migration,
but the immutable preregistration binds exact selected-carrier bytes.

**Reach:** H00 blocks export and the unopened primary until the migration
meaning is reviewed. No primary is run to test whether this issue matters.

**Verdict:** sound; retains source custody and the once-only study contract.
**Confidence:** high.

## Installed typing reuses the real wheel boundary

**When:** P01 implementation.

**Choice:** The locked development checker inspects the same isolated wheel
environment already used for runtime acceptance. An empty explicit config,
cleared checker variables and disabled cache prevent checkout configuration
from supplying types. Exact positive types, every resolved package path and a
single expected invalid-mode diagnostic are checked together.

**Gap:** Shipping an empty `py.typed` marker alone does not prove that consumers
receive useful types or that the checker rejects an invalid call.

**Reach:** The existing distribution test gains the checks; the wheel gains no
checker dependency or second build path. Supported interpreter/platform lanes
still require their own execution. This does not close C04.

**Verdict:** sound; verifies the installed consumer contract directly.
**Confidence:** high after the local Python 3.14 smoke; hosted lanes pending.

## Dependency layers describe manifested edges

**When:** L01 dependency review.

**Choice:** The existing landscape parser recognizes plain/public imports after
the shared comment/string masking. Manifested cycles stop generation. Generated
aggregate imports remain visible without pretending to expand their full DAG.

**Gap:** Ignoring `public import` erased every maintained dependency and let a
vacuous test accept one false layer. The old cycle fallback could also publish
an invalid ordering.

**Reach:** The existing projection and its tests own the correction. Lake keeps
authority over the complete build plan; imports establish no proof relations.

**Verdict:** sound; restores the measured graph and rejects false orderings.
**Confidence:** high after positive-edge, cycle and projection checks.

## The root exports its Lean theorem without Mathlib

**When:** L01 root import narrowing.

**Choice:** Remove the sole Mathlib import while preserving the existing root
declaration and proof exactly. The standalone root and a real importing consumer
compile with only the Lean standard library available.

**Gap:** The root's `True` theorem did not use the thousands of Mathlib imports
it re-exported. Issue #109 explicitly requests narrowing that root dependency.

**Reach:** Internal exact-root imports were searched; none were found. Consumers
that relied on the incidental Mathlib re-export must import their dependencies
explicitly. No foundation or topic theorem changes in this pass, and the six
blanket foundation imports and 21 topic-body imports remain open.
The package's header gate now names module/exposure conventions and projection
parity explicitly; narrowing intentionally changes imports while preserving
the theorem signatures, proofs and axioms.

**Verdict:** sound; the declared FEP theorem is preserved and its dependency is
tested directly. External consumers of the incidental re-export are unaudited.
**Confidence:** high for the checked root and consumer; no measured speedup claim.
