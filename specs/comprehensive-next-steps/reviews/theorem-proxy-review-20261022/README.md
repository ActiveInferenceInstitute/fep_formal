## Relative proof estimates

These estimates describe proof scope and uncertainty, not elapsed time or
promised delivery dates. Inspect existing owners and callers before generating
new proofs. Each estimate includes its meaningful controls and review burden.

| Cohort | Relative scope | Main uncertainty / minimum proof increment |
| --- | --- | --- |
| Reuse finite Gibbs/control proofs | Small–medium | Existing constructor and minimizer are proved; exact carrier, sign, temperature and public API bridges may be enough. Avoid duplicate proof implementation. |
| Trajectory filtering and smoothing | Medium–large | Requires a common finite trajectory law, positive-evidence recursion and identification of conditional marginals; components already exist. |
| Sampling risk and concentration | Medium | Instantiate actual iid laws, indicator independence, moments and tail bounds; finite/native transport and endpoint controls can dominate integration. |
| Primary alignment 063/064 | Small proof increment, medium integration | One existing-theorem wrapper and selector changes; historical API custody, sparse controls and deterministic projections require full review. |
| Statistical regularity and convex projection | Medium–large | Derive score-covariance and first-order conditions from actual differentiable models/minimizers; current certificates are not those derivations. |
| Generic Gaussian blanket | Large / high uncertainty | Residual product-law lemmas are only a start; precision algebra, conditional disintegration, Fin4 recovery and a genuine conditional countermodel remain. |
| Markov reversal and work protocols | Large / high uncertainty | Construct an actual finite physical protocol deriving path/work normalization; continuum and singular extensions are separate, larger scopes. |

A smaller bridge discovered during source inspection should replace an
unnecessary new theorem. A missing pinned-library lemma may expand a cohort or
produce a documented stop gate; compilation alone never resolves its scientific
interpretation.

## Acceptance boundary

Publishing a source-only report is distinct from implementing its proof
roadmap. Independent final semantic review must check the aggregate correction,
statement/definition interpretation, nearest-topic boundaries and proposed
controls. Any implemented slice must use the frozen owner contract, preserve
old API custody, regenerate deterministic projections and qualify its exact
source with native/axiom, local and hosted evidence. The open TODO row for #75
remains until its complete closure rule is independently satisfied at an
accepted source epoch. This report accepts no H3, empirical, capture, provider
or broad scientific-primary claim.
