# fep_lean/manuscript/

Authored paper sections, bibliography, and static Pandoc configuration. Paths
below are relative to the project root.

## Ownership and projections

- Authored numbered `*.md` files remain reusable templates containing typed
  `{{...}}` placeholders.
- `manuscript_vars.yaml` is generated by
  `fep_lean.output.manuscript.write_manuscript_vars`.
- `09z_unified_formalism_catalogue.md` is generated from the complete validated
  `FEPTopicCatalogue`; it contains the Lean and typeset appendix material for
  every topic. Never edit it by hand.
- `scripts/render_manuscript.py` validates the full placeholder inventory
  before rendering to `output/manuscript/`. It must never mutate authored
  section files.
- Formalism counts used in prose come from the `formalism` manuscript-variable
  block, which is itself projected from canonical coverage. Do not copy them as
  literals.

The catalogue itself is a generated join. Stable metadata is maintained in
`config/catalogue_metadata.yaml`, semantic scope in
`config/theorem_maturity.yaml`, expansion novelty in
`config/formalism_novelty.yaml`, Lean bodies in family modules under
`src/fep_lean/catalogue/bodies/`, and theorem-signature projection in
`src/fep_lean/catalogue/latex.py`. `config/topics.yaml` and packaged
`src/fep_lean/data/topics.yaml` are byte-identical projections.

## Evidence boundaries

- Catalogue mode provides deterministic artifact-generation evidence only.
- A validated native receipt establishes exact-roster Lean compilation with
  source/toolchain binding, zero `sorry`, and (for claim readiness) zero
  warnings. It does not establish an LLM or OpenGauss run.
- Full-run/Hermes prose is enabled only by a report for which
  `validate_report_receipt(...).claim_ready` is true.
- `mathlib_status` records syntactic support; `semantic_disposition` records
  topic-level reach. Never infer one from the other.

## Required publication checks

```bash
uv run fep-lean catalogue
uv run fep-lean atlas --check
uv run fep-lean dashboard --check
uv run python scripts/audit_formalisms.py \
  --receipt output/formalism-audit.json
uv run python scripts/render_manuscript.py --check
uv run python docs/theorem_ref_audit.py
uv run python docs/citation_audit.py
uv run python docs/pin_audit.py
uv run python docs/xref_audit.py
uv run python docs/check_links.py --strict --include-root
uv run python scripts/build_render_fonts.py --check
```

Publishing runs one command, not two:

```bash
FEP_LEAN_TEMPLATE_DIR=<template checkout> \
  uv run python scripts/render_publication.py
```

It renders the authored sources into `output/manuscript/` (the directory the
shared template actually typesets), runs the template's PDF stage, and then
runs `scripts/check_render_log.py`. Running the template stage on its own
typesets whatever that directory last held and accepts a log recording TeX
errors and dropped glyphs, because the template's success test looks for four
fatal markers under `-interaction=nonstopmode`.

Every `{{placeholder}}` in an authored chapter must be emitted by
`src/fep_lean/output/manuscript.py::build_manuscript_vars` and resolve under
`scripts/render_manuscript.py --check`. Add a regression whenever a new
placeholder family is introduced; never populate a run-bound value from a
configuration default or an unvalidated receipt.

`07_references.md` carries the section heading and a raw-LaTeX
`\bibliography{references}` call; the entry list itself is emitted by BibTeX
from `references.bib`, so there is no hand-maintained index to keep aligned.
The heading must keep the word "References" -- the combined renderer detects an
explicit references section by that word and suppresses natbib's duplicate
heading only when it matches. Every citation key must resolve and bibliographic
claims must be grounded in a verifiable primary or published source.

## Conventions

- Cite the generated appendix instead of copying catalogue bodies into prose.
- A table cell naming Lean modules is a token, never a literal: the
  framework chapters print `{{topics.fep-NNN.imported_modules}}`, computed
  from each row's own imports. Forty of seventy-one hand-typed cells had
  drifted before it was generated.
- Pedagogical Lean snippets are allowed only when clearly separated from
  canonical `fep-NNN` declarations.
- Do not hard-code changing run metrics, toolchain values, semantic totals, or
  provider results. Add a typed manuscript variable and a regression test.
- Chat notation rules do not alter the manuscript's native Pandoc/LaTeX syntax.
