The accepted H1
record preserves the first uninhabited carrier merge and separately proves the

and scientific firewalls. H3 rows remain prospective rather than theorem or

The released catalogue establishes many exact finite, measure-theoretic,
geometric, control, learning, and thermodynamic results. Its own limitations
identify the next problem: those results do not yet form one end-to-end
scientific derivation from dynamics through inference and action to an
empirically testable claim. This program therefore makes **vertical depth and
falsifiability** the progress measures. Topic count is explicitly a non-goal.

## North star

Produce one typed theorem chain with preserved countermodels:

```text
dynamics and observation law
  -> stationarity or predictive law
  -> blanket or conditional-independence claim
  -> posterior and variational bound
  -> decision risk and policy objective
  -> action or controlled transition
  -> thermodynamic or Lyapunov consequence
  -> executable prediction
  -> preregistered empirical test
```

Every arrow must be either a proved implication, an explicitly supplied
scientific assumption, or a retained counterexample showing why the arrow does
not follow. A conjunction of independently true endpoint theorems is not a
vertical chain.

## Progress measures

The program reports these measures instead of rewarding catalogue growth:

- **derivational depth:** the longest reviewed `formal` chain that shares
  actual carriers and intermediate values;
- **assumption discharge:** which previously supplied premises are derived on
  the selected model, and which remain hypotheses;
- **countermodel coverage:** which headline implications have an executable
  negative boundary;
- **carrier transfer:** which clauses survive finite, measure-valued, smooth,
  and continuous-time instantiation without changing meaning;
- **identifiability and recovery:** which latent variables and parameters can
  be recovered before real-data claims open; and
- **evidence maturity:** the strongest independently accepted plane for each
  claim, never a single aggregate percentage.

Topic count, declaration count, relation count, and numerical-panel count are
reported only as maintenance facts. Increasing them is not a research result.

## Decisions fixed by this design

Three independent planning passes were reconciled: a minimal dependency ladder,
a risk-first falsification program, and a seam/ownership review. The synthesis
fixes the following choices so an implementing agent does not reopen them:

1. **A prerequisite seam audit belongs at H1.0.** It corrects stale claims about
   the pinned library, checks composition ownership, and runs exact API probes.
   It does not add mathematics or promote any topic.
2. **Finite integration comes before generalization.** H1 produces one
   connected posterior--decision--action certificate and one stationary
   blanket countermodel before H2 opens. It does not relabel that one-step
   decision as transition-aware planning.
3. **Countermodels are acceptance-critical.** Blanket conditional independence,
   stationarity, sparse coupling, and rowwise factorization must not silently
   become inference, causal identification, or free-energy descent.
4. **Native extended KL is the cross-carrier information currency.** The
   project's totalized real finite KL remains useful on its stated carrier but
   is not equated with native `klDiv` under singular support.
5. **Continuous time starts with semigroups and explicit Gaussian transition
   laws.** The pinned tree has Brownian laws but no integrated Itô/SDE/
   Fokker--Planck development; diffusion claims remain stop/go work.
6. **The scientific target constrains the abstractions.** H2 must not build a
   general manifold, stochastic-calculus library, or simulator unrelated to
   the H3 case study.
7. **No future topic IDs are reserved.** A proved terminal theorem may motivate
   a later catalogue row only through the existing novelty and semantic-review
   gates.
8. **No second research registry is introduced.** This directory owns
   prospective goals. Active implementation and blocker state remains
   spec-owned until an accepted theorem supplies source-bound evidence for the
   existing relation/capability owners. Opening a spec alone creates no
   capability, novelty, or catalogue claim.
9. **Terminal work uses merge barriers, not a misleading shortest path.** Every
   solid incoming lane is mandatory until a reviewed no-go revises both the
   theorem clause and the dependency graph.
10. **One carrier owns each vertical theorem.** H1 equates the emitted action's
    generative transition with the action-indexed sampled semigroup on the
    sixteen-state blanket carrier, while retaining the rejected first merge as
    a no-go for its old carriers. H2 uses one scalar Gaussian location/OU model
    for geometry, filtering, control, and dissipation.
11. **The native action-indexed lift belongs to H2.4.** Its H1 regression is an
    exact `embeddedKernel` equality on the same action, time, and
    right-associated state carrier; H3 cannot introduce a replacement action
    interface.
12. **The coupled Gaussian carrier lands in H2.5.** The exact symmetric
    precision `K`, derived `Sigma = K⁻¹`, four-coordinate semigroup, and scalar
    specialization are merge prerequisites for H2.7. H3.G0 only accepts their
    source-bound evidence and selects a branch.
13. **H3 derives scientific conclusions from primitives.** `Axis ≃ Fin 4`, the
    explicit H1 tuple permutation, dimensionless state, and positive affine
    raw-unit bridge are fixed seams. Covariance, invariance, recognition, and
    identifiability are theorems, not model fields, and continuous/finite
    branches never hybridize.
