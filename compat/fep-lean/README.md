# Deprecated `fep-lean` distribution

This metadata-only compatibility distribution depends on the matching
`fep-formal` version. Install `fep-formal` directly for new work.

The canonical distribution owns all code and both console commands. This
distribution owns no modules or commands, so it cannot delete shared code on
uninstall. It does not replace already published wheels: migration and release
ordering are described in [the cutover guide](../../docs/identity-migration.md).
